THE ONNX ORACLE FIXTURES
========================
Small ONNX models, and the outputs ONNX Runtime's own Python tools produced from
them, checked in so the managed codec and the managed quantizer can be tested
byte for byte with nothing installed.

WHO OWNS THEM
    They are OURS. Every file here was generated by generate_fixtures.py in this
    same folder, from weights that script makes up with a seeded random number
    generator - no publisher's model, no third-party data and no downloaded file
    is among them. They carry this repository's licence (MIT); see LICENSE at
    the root.

HOW THEY WERE MADE
    generate_fixtures.py, run BY HAND, once, in a virtual environment holding
    onnx and onnxruntime. It writes each input model, then writes what ONNX
    Runtime's quantization tools make of it beside it under a suffix that names
    the mode. The test suite NEVER runs it: the tests read the files as they are
    checked in, which is the whole point - the numbers they compare against were
    produced by someone else's implementation, not by ours.

WHY THERE ARE TWO COPIES OF THIS FOLDER
    tests/CodeBrix.Ollama.Core.Tests/Onnx/Fixtures/ and
    tests/CodeBrix.Ollama.ModelManager.Tests/Onnx/Fixtures/ hold the same files.
    The CODEC lives in CodeBrix.Ollama.Core and the QUANTIZER in
    CodeBrix.Ollama.ModelManager, so their tests are in two projects, and a test
    project does not read another test project's assets. Regenerating means
    running the script once and copying its output into both folders.
