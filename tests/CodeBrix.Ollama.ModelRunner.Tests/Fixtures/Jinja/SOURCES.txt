=======================================================

whose MODEL REPOSITORY LICENSE is Apache-2.0 or MIT. Nothing under any other license is included -
no Llama, no Gemma, no license:other repository.

Each one was fetched anonymously on 2026-09-16 with

    curl -sSL https://huggingface.co/<repo>/resolve/main/<file>

trying chat_template.jinja first and tokenizer_config.json second; where the file fetched was
tokenizer_config.json, the fixture is the value of its "chat_template" member, written out verbatim.
The commit is the sha the resolve URL redirected to, as reported in the x-repo-commit response
